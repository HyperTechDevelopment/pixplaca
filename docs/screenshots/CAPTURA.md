# Checklist de captura — docs/screenshots/

Gere as imagens do README com o app rodando (`pnpm dev`).

## Configuração

1. Viewport de 1440×900, zoom de 200% (equivale a @2x).
2. Tema claro (use o botão Sol/Lua no topo e deixe no claro).
3. Feche o DevTools e tire o cursor da área da captura.

## hero.png (obrigatório)

1. Abra a página inicial.
2. Confirme que a placa de exemplo está visível ao lado do título.
3. Capture do topo até o fim da dobra do hero.

## studio.png (pendente — o README ainda não referencia)

Capturas de estúdio e de placa exportada entram no README quando os arquivos existirem. Mesmos dados de teste.

1. Role até o estúdio.
2. Preencha com os dados de teste:
   - Chave: `loja@exemplo.com.br`
   - Nome: `Cantina Central`
   - Cidade: `São Paulo`
3. Escolha 1 design colorido e legível.
4. Capture o editor com a prévia ao lado.

## placa-exemplo.png (opcional)

1. Com os mesmos dados de teste, baixe o PNG pelo botão do estúdio.
2. Salve o arquivo baixado como `placa-exemplo.png`.

## Depois de capturar

1. Comprima cada arquivo (TinyPNG ou Squoosh), teto de 600 KB por arquivo.
2. Salve com os nomes exatos em `docs/screenshots/`.
3. Abra o README no GitHub e confira se as imagens carregam.

## Regras

- Nunca use sua chave Pix real: o QR ficaria público no repositório.
- Não fotografe DevTools, console ou cursor sobre a placa.
